📱 ТРИ ВАРИАНТА ЗАПУСКА:

═══════════════════════════════════════════════════════════════════

1️⃣  ЛОКАЛЬНО (для разработки)

  1. Открой терминал в папке telegram-mini-app
  2. npm install
  3. npm run dev
  4. Откройся: http://localhost:3000

  ✓ Готово за 3 минуты!

═══════════════════════════════════════════════════════════════════

2️⃣  НА VERCEL (облако - рекомендуется)

  1. npm run build
  2. npm install -g vercel (если не установлен)
  3. vercel
  4. Следуй инструкциям

  ✓ Твой App готов на: https://legend-mini-app.vercel.app

═══════════════════════════════════════════════════════════════════

3️⃣  TELEGRAM BOT (полная интеграция)

  1. Открой @BotFather в Telegram
  2. Отправь: /start → /newbot
  3. Название: ЛЕГЕНДА Bot
  4. Юзернейм: legend_barbershop_bot
  5. Сохрани TOKEN
  6. Отправь @BotFather: /setmenubutton
  7. Настрой URL: https://legend-mini-app.vercel.app
  8. Кнопка текст: 🎭 Открыть ЛЕГЕНДУ

  ✓ Открой бота и кликни кнопку!
