ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК:


❌ "npm: command not found"

  РЕШЕНИЕ: Установи Node.js
  1. Переди на https://nodejs.org/
  2. Скачай LTS версию
  3. Установи (Next → Next → Finish)
  4. Перезагрузи компьютер
  5. Попробуй npm run dev снова


❌ "Port 3000 already in use"

  РЕШЕНИЕ: Измени порт
  1. Открой файл: vite.config.js
  2. Найди: server.port = 3000
  3. Измени на: server.port = 3001
  4. Сохрани (Ctrl+S)
  5. Перезапусти: npm run dev


❌ "Cannot find module 'react'"

  РЕШЕНИЕ: Переустанови
  1. Нажми Ctrl+C в терминале (останови сервер)
  2. Выполни: npm install
  3. Потом: npm run dev


❌ Терминал выглядит странно / красный текст

  РЕШЕНИЕ: Обычно это ОК, просто ошибок нет. Смотри:
  - Ищи строку "Local: http://localhost:3000"
  - Если видишь → всё работает!
