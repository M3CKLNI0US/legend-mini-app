## 📞 ПОМОЩЬ

### Если не работает npm install:
```bash
# Проверь Node.js
node --version  # должно быть 16+

# Чисти кеш
npm cache clean --force

# Переустанови
rm -rf node_modules package-lock.json
npm install
```

### Если порт 3000 занят:
```bash
# Открой vite.config.js
# Найди: server.port = 3000
# Измени на: server.port = 3001
```

### Если нет интернета:
```bash
# npm install работает оффлайн (если node_modules был)
npm run dev  # работает локально
```

### 💡 Для разработки:
1. Используй VS Code с расширениями (Tailwind CSS IntelliSense)
2. Открой DevTools браузера (F12) для отладки

1. Всё делай через TailwindCSS классы
2. Кастомные цвета в `tailwind.config.js`
3. Анимации в `App.css`

1. Один компонент = один файл
2. Используй props для передачи данных
3. State через `useState` hook

### 💡 Для API:
1. Все функции в `src/utils/api.js`
2. Используй `useTelegramApp()` для Telegram API
