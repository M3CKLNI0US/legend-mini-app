1️⃣  ЛОКАЛЬНО (САМЫЙ БЫСТРЫЙ - 2 МИНУТЫ):

  1. Открой Command Prompt / PowerShell / Terminal
  2. Перейди в папку:
     cd c:\Users\74\LegendProject\telegram-mini-app
  
  3. Установи зависимости:
     npm install
  
  4. Запусти приложение:
     npm run dev
  
  5. В браузере открой:
     http://localhost:3000

  ✅ ГОТОВО! Видишь черный интерфейс с золотом?

2️⃣  НА ОБЛАКЕ VERCEL (БЕЗ СЕРВЕРА):

  1. npm run build
  2. npm install -g vercel (если нет)
  3. vercel
  4. Следуй инструкциям

  ✅ Твой App на: https://legend-mini-app.vercel.app


═══════════════════════════════════════════════════════════════════

3️⃣  TELEGRAM BOT (ПОЛНАЯ ИНТЕГРАЦИЯ):

  1. Откройся @BotFather в Telegram
  2. /start → /newbot
  3. Название: ЛЕГЕНДА Bot
  4. Юзернейм: legend_barbershop_bot
  5. Сохрани TOKEN
  6. @BotFather → /setmenubutton
  7. Настрой Menu Button с URL
  8. Кликни кнопку в боте

  ✅ Готово!

🎯 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:

  ❌ "npm: command not found"
  ✅ Установи Node.js → https://nodejs.org/

  ❌ "Port 3000 already in use"
  ✅ Измени порт в vite.config.js или используй port 3001

  ❌ "Cannot find module 'react'"
  ✅ npm install

  ❌ "Styles not applied"
  ✅ Перезагрузи браузер (Ctrl+Shift+R)

  ❌ Не знаю что дальше?
  ✅ Читай START_HERE.md или INSTALLATION.md
